<h1 id="Solving-a-Search-Problem-with-a-Quantum-Computer">Solving a Search Problem with a Quantum Computer¶</h1><p>In computer science, satisfiability problems are known to be difficult to solve (often NP-Hard, no polynomial time algorithms). A satisfiability problem generally refers to finding a solution(s) that satisfy the logical conjuntion ("AND") of multiple propositions. For example, 3-SAT problem, a widely known NP-Hard problem, refers to the conjunction of multiple disjunctions ("OR") of 3 elements (e.g., $(a_{1} \lor b_{1} \lor c_{1}) \land (a_{2} \lor b_{2} \lor c_{2}) \land \ldots \land (a_{N} \lor b_{N} \lor c_{N})$).</p> <p>We are going to encode a short 3-SAT problem using revkit and solve it using Qiskit.</p>

letters = "abcdefghijklmnopqrstuvwxyz"
def get_n_symbols(_logic):
    count = 0
    for l in letters:
        if l in _logic:
            count = count + 1
    return count

import os 

def get_api_key(env_var_name=None, ext_file_path=None):
    my_token = None
    if env_var_name is not None:
        my_token = os.environ.get(env_var_name)
        QiskitRuntimeService.save_account(token=my_token, overwrite=True)
    elif ext_file_path is not None:
        with open(ext_file_path, "r") as f:
            my_token = f.read()
            QiskitRuntimeService.save_account(token=my_token, overwrite=True)
    else:
        print("You saved it, right?")
